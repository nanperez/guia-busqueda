# Guía interactiva para la búsqueda bibliográfica

Sitio estático de una sola página, preparado para publicarse con GitHub Pages. No requiere instalación de dependencias ni proceso de compilación.

## Publicación con GitHub Pages

1. Crea un repositorio en GitHub y sube `index.html` y este `README.md` a la raíz de la rama `main`.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`, y guarda los cambios.
5. Espera a que GitHub Pages publique el sitio. La URL aparecerá en la sección **Pages**.

El ejemplo sobre KIBS peruanas se encuentra precargado en el widget. Los enlaces externos a bases académicas y herramientas de búsqueda requieren conexión a internet.
